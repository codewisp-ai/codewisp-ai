### 2. ⚡ [VortexMQ](https://github.com/codewisp-ai/VortexMQ) — High-Throughput Event-Driven Notification Engine

> *A fault-tolerant, horizontally scalable asynchronous messaging & notification pipeline built on Redis Streams, competing consumer groups, non-blocking ZSET retry queues, and real-time Prometheus/Grafana observability.*

| Dimension | Engineering Implementation |
|:---|:---|
| **Stack** | `Node.js (ES Modules)` · `Express` · `Redis Streams & ZSET` · `Socket.IO` · `Prometheus` · `Grafana` · `Docker Compose` |
| **Ingestion & Broker** | Stateless Producer API with sub-5ms `O(1)` `XADD` stream persistence (`MAXLEN ~ 100k`) returning instant `202 Accepted` responses |
| **Resilience & Recovery** | Competing consumers via `XREADGROUP`, non-blocking exponential backoff + jitter via `ZSET` (`ZRANGEBYSCORE`), stalled PEL job recovery daemon (`XAUTOCLAIM`), and Dead Letter Queue (`DLQ`) isolation |
| **Real-Time & Telemetry** | Cross-container `Redis Pub/Sub` → `Socket.IO` bridge for sub-100ms browser status updates + `prom-client` metrics scraped every 5s |
