> **The problem:** Citizens have no easy way to report and track civic issues like broken roads, water leaks, or faulty streetlights.

**What I built:**
- 🤖 AI-driven issue classification & auto-routing to the right department
- 📍 Geo-tagged reports with live map visualization
- 🔔 Real-time status updates via notification system
- 🧩 Microservice architecture — scalable by design
- 🌐 MERN Stack + Docker containerized deployment
